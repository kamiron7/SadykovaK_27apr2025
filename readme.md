
# 📋 Инструкция по работе с Postman-коллекцией "Sibdar Cart Smoke Tests"

## Описание

Эта коллекция предназначена для смоук-тестирования основных функций корзины на сайте **[https://www.sibdar-spb.ru](https://www.sibdar-spb.ru)**.

Тестируются следующие сценарии:

-   Добавление товара в корзину
    
-   Изменение количества товара
    
-   Удаление товара из корзины
    
-   Получение списка товаров в корзине
    

## Требования

-   Установленный Postman (рекомендуемая версия 10.x или выше)
    

## Переменные коллекции

Переменная

Описание

`base_url`

Базовый URL сайта. По умолчанию: `https://www.sibdar-spb.ru`

> ⚡ Обрати внимание: переменная `auth_token` в этой коллекции пока **не используется активно** — заголовок `Authorization` добавлен, но сам токен нужно будет либо убрать, либо заполнить вручную, если авторизация потребуется.

## Список доступных запросов

Название запроса

Описание

**Add Item to Cart**

Добавление товара в корзину через `basketOrder.php` с типом `add`

**Change Quantity**

Изменение количества товара  через `basketOrder.php` с типом `plus`

**Remove Item from Cart**

Удаление товара из корзины через `basketOrder.php` с типом `delete`

**Get Cart Items**

Получение списка товаров в корзине через `basketList.php`

## Как работать с коллекцией

1.  Откройте Postman.
    
2.  Нажмите **Import** → выберите файл коллекции (`e2c87148-35f3-4f00-bcac-2f6b74736fad.json`).
    
3.  После импорта коллекции:
    
    -   Проверьте значение переменной `base_url`.
        
    -   При необходимости добавьте значение `auth_token` (если потребуется авторизация).
        
4.  Выполняйте запросы по порядку:
    
    -   Сначала **Add Item to Cart**.
        
    -   Затем можно **Change Quantity**.
        
    -   Потом **Get Cart Items** для проверки.
        
    -   И **Remove Item from Cart** для удаления товара.
        
5.  После выполнения каждого запроса проверяйте тело ответа и код статуса (`200 OK` или другие).
    

## Особенности

-   Все запросы работают через **POST**, даже для изменения количества и удаления товара.
    
-   Операция управляется через параметр `type` в теле запроса:
    
    -   `"type": "add"` — добавить товар.
        
    -   `"type": "plus"` — увеличить количество.
        
    -   `"type": "delete"` — удалить товар.
        
-   Идентификаторы `idCookie` и `idProd` сейчас заданы статически (`736599` и `178`). При необходимости замените на реальные значения.
